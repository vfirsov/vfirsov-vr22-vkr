# Architecture Decision Records (ADR)

В этой папке хранятся записи об архитектурных решениях (Architecture Decision
Records) информационной веб-системы для управления продажами и учёта
ассортимента в чайном магазине.

Каждая запись фиксирует контекст, принятое решение, рассмотренные альтернативы
и последствия. Принятые записи не редактируются по существу: изменение решения
оформляется новой записью, которая заменяет предыдущую.

## Соглашения

- Имя файла: `NNNN-краткое-название.md`, где `NNNN` — сквозной номер записи.
- Статусы: `Предложено`, `Принято`, `Отклонено`, `Заменено ADR-NNNN`.
- Архитектурные схемы приводятся в нотации [C4](https://c4model.com/) и
  оформляются диаграммами Mermaid непосредственно в тексте записи.
